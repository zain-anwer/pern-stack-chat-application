# Bubble Chat Backend

Backend service for a real-time chat application built with the PERN stack (PostgreSQL, Express.js, React, Node.js).

## Features

- Real-time messaging with Socket.IO
- JWT-based authentication
- Rate limiting and bot protection
- PostgreSQL persistence
- REST API endpoints
- Online/offline user presence
- Group-chat extensible architecture

## Technology Stack

- Node.js
- Express.js
- Socket.IO
- PostgreSQL
- JWT
- Arcjet

## Deployment

This Hugging Face Space hosts the backend service used by the Bubble Chat application.
